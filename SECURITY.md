# Security Policy

We take security vulnerabilities seriously. Thank you for helping keep our projects secure.

---

## Supported Versions

| Branch | Supported |
| :--- | :--- |
| `main` | ✅ Yes |
| `nightly` | ⚠️ Pre-release only |
| Others | ❌ No |

---

## Reporting a Vulnerability

If you discover a security issue or vulnerability:

1. **Do NOT open a public GitHub issue.**
2. Send an email to the repository maintainers / organization security team at:
   `security@oneiricmatrix.com` *(or configure GitHub Private Vulnerability Reporting)*
3. Include as much information as possible:
   - Type of issue (e.g. injection, auth bypass, secret leak, denial of service)
   - Step-by-step reproduction steps or proof-of-concept
   - Affected files and components
   - Potential impact and suggested mitigation

### Response Timeline
* **Initial Acknowledgement**: Within 48 hours.
* **Assessment & Fix Plan**: Within 5 business days.
* **Coordinated Disclosure**: Fix released to `main` via the promotion pipeline before public disclosure.
